# Инструкция: Как получить / скачать APK игры Life Simulator EX

В игре уже встроены 100% автономный движок, Service Worker, манифест и иконки. Вы можете получить приложение на телефон любым удобным способом:

---

## Способ 1: Установка как нативное приложение (WebAPK) прямо на телефон за 15 секунд (Без ПК-компилятора)
Самый быстрый и удобный способ без необходимости устанавливать 4 ГБ Android Studio.

1. Запустите проект на компьютере:
   ```bash
   npm run start
   ```
2. Узнайте локальный IP-адрес вашего компьютера в домашней Wi-Fi сети (в командной строке `ipconfig`, например `192.168.1.45`).
3. Откройте в браузере **Google Chrome на Android-смартфоне**:
   `http://192.168.1.45:3000`
4. В Chrome нажмите меню **«⋮» (три точки вверху)** -> **«Установить приложение»** (или «Добавить на главный экран»).
5. **Результат:** Android скомпилирует системный нативный **WebAPK**:
   - Приложение появится на рабочем столе с собственной иконкой.
   - Запускается в полноэкранном режиме (без рамок браузера).
   - Работает **100% автономно и без интернета** (все файлы, база из 640 профессий, диорама и ИИ сохраняются в локальный оффлайн-кэш телефона).

## Способ 2: Получить готовый установочный файл `.apk` через PWABuilder (Бесплатно от Microsoft)
Если вам нужен именно отдельный файл `.apk`, чтобы отправить его в Telegram или установить через Проводник:

1. Опубликуйте сайт на любой бесплатный хостинг (например, Vercel, Render, Cloudflare Pages, Netlify) или временно откройте доступ через ngrok / localtunnel:
   ```bash
   npx localtunnel --port 3000
   ```
2. Откройте сервис: **[PWABuilder.com](https://www.pwabuilder.com)**.
3. Вставьте ссылку на игру и нажмите **Start**.
4. Нажмите кнопку **Package for Stores** -> выберите **Android** -> **Generate APK / Package**.
5. Сервис сгенерирует готовый подписанный `.apk` файл для скачивания!

---

## Способ 3: Автоматическая сборка APK в облаке через GitHub Actions (0 байт на вашем ПК)
В проект уже добавлен готовый файл автоматизации `.github/workflows/build-apk.yml`.

1. Загрузите проект в ваш GitHub-репозиторий (public или private).
2. Перейдите во вкладку **Actions** в репозитории на GitHub.
3. Выберите **Build Android APK** -> нажмите **Run workflow**.
4. Сервер GitHub за 2–3 минуты автоматически соберет APK-файл на чистой виртуальной машине с Android SDK и выложит готовый **`LifeSimulatorEX-APK.zip`** со скачиваемым `app-debug.apk` в разделе артефактов.

---

## Способ 4: Локальная сборка `.apk` через Capacitor (если у вас установлен Android Studio)
Если у вас на компьютере установлен Android Studio:

```bash
# 1. Установить зависимости Capacitor
npm install @capacitor/core @capacitor/cli @capacitor/android --save

# 2. Собрать веб-ресурсы игры
npm run build

# 3. Инициализировать Android-проект
npx cap init LifeSimulatorEX com.lifesimulator.ex --web-dir dist
npx cap add android

# 4. Открыть проект в Android Studio
npx cap open android
```
В открывшемся Android Studio выберите: **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
Готовый `.apk` появится в `android/app/build/outputs/apk/debug/app-debug.apk`.
