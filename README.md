# LIFE SIMULATOR EX (APK OFFLINE AI)

100% автономный текстово-визуальный симулятор жизни на React, TypeScript, Tailwind CSS и Vite с процедурной Hi-Bit диорамой, оффлайн ИИ-движком и полной поддержкой мобильных устройств (PWA / APK).

---

## Быстрый запуск на ПК (Локально)

**Требования:** Установленный [Node.js](https://nodejs.org/) (версия 18 или новее).

1. **Установите зависимости:**
   ```bash
   npm install
   ```

2. **Запустите игру:**
   ```bash
   npm run dev
   ```

3. Откройте в браузере: **`http://localhost:3000`**

> **Нужен ли GEMINI_API_KEY?**  
> **НЕТ!** В игру встроен легковесный **100% автономный офлайн ИИ-генератор** событий с памятью ДО/ПОСЛЕ (`aiMemoryLog`), базами на 77 городов, 640 профессий, ВУЗами 27 стран мира и процедурной диорамой. Ключи и сервера не требуются. Игра работает даже при полном отключении интернета.

---

## Запуск на телефоне (Как автономный APK)

### Вариант 1: Установка без Android Studio (через браузер в 1 клик)
1. Откройте игру на телефоне в браузере Google Chrome или Яндекс.Браузер.
2. Нажмите на иконку меню браузера (три точки) → **«Установить приложение»** (или **«Добавить на главный экран»**).
3. На рабочем столе появится иконка **Life Simulator EX**, которая запускается в полноэкранном режиме и работает без подключения к сети.

### Вариант 2: Сборка установочного `.apk` файла (Capacitor)
```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "Life Simulator EX" com.lifesimulator.ex --web-dir dist
npm run build
npx cap add android
npx cap open android
```
В открывшемся Android Studio выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

## Основные возможности
* **Старт с 0 лет:** Выбор точной даты рождения, имени, города (77 городов Украины, Европы, курортов и мира).
* **60 скинов персонажа** с процедурной диорамой (рост персонажа от младенца до взрослого, динамическая мускулатура и телосложение).
* **Возрастная система:**
  - 0–5 лет: Младенчество, детские фокусы, уход родителей.
  - 6–11 лет: Школа, кружки, репетиторы, языковые курсы.
  - 12–13 лет: Подростковая романтика, первые хобби, сборка ПК.
  - 14–17 лет: Подростковые подработки, колледжи, карманные деньги от родителей.
  - 18+ лет: 640 профессий, бизнес и франшизы, ВУЗы Топ-10 по 27 странам, криминал, казино 777, стероиды, эскорт, автотюнинг и недвижимость.
* **Родительская механика:** Запрос на покупку питомца (стартовый шанс 1.5%), спонсорство курсов и техники, карманные деньги.
* **Автосохранение:** Каждое действие сохраняется в локальное хранилище устройства (`localStorage`) с возможностью экспорта/импорта файла сохранения в формате JSON.
